# ระบบบันทึกข้อมูลผู้สูงอายุ (ต้นแบบ)

เว็บต้นแบบสำหรับแทนการจดบนกระดาษ ได้แก่ บันทึกการตรวจ (สัญญาณชีพ), บันทึกทางการพยาบาล, ตารางให้ยา และรายงาน
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีเปิดใช้งาน
ต้องมี Python 3 (Mac มีมาให้แล้ว) ไม่ต้องติดตั้งอะไรเพิ่ม

1. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `python3 server.py`
2. เปิดเบราว์เซอร์ที่ http://localhost:8000
3. **ครั้งแรก**: สร้างบัญชีหัวหน้า / ผู้ดูแลระบบ แล้วเลือกว่าจะเริ่มจากข้อมูลว่าง ข้อมูลตัวอย่าง หรือข้อมูลที่เคยกรอกในเบราว์เซอร์นี้
4. เพิ่มบัญชีให้พนักงานทุกคนที่เมนู "จัดการผู้ใช้"

**ใช้จากเครื่องอื่น** (แท็บเล็ต มือถือ คอมพิวเตอร์อีกเครื่อง) ที่ต่อ Wi-Fi เดียวกัน:
เปิดที่อยู่ที่ขึ้นตอนรันเซิร์ฟเวอร์ เช่น `http://192.168.1.20:8000`
เครื่องที่รัน `server.py` ต้องเปิดไว้ตลอดเวลาที่ใช้งาน

## ข้อมูลและการสำรอง
- ข้อมูลทั้งหมดอยู่ในไฟล์ `data/care.db` บนเครื่องที่รันเซิร์ฟเวอร์
- ระบบสำรองอัตโนมัติวันละครั้งที่ `data/backups/` (เก็บย้อนหลัง 30 วัน)
- หัวหน้ากด "ดาวน์โหลดสำรองข้อมูล" ใต้เมนูซ้ายได้ ควรเก็บสำเนาไว้นอกเครื่องสัปดาห์ละครั้ง (เช่น USB หรือ Drive ของศูนย์)
- กู้คืน: ปิดเซิร์ฟเวอร์ แล้วคัดลอกไฟล์จาก `data/backups/` มาทับ `data/care.db`
- ถ้าเน็ตหลุดระหว่างบันทึก ข้อมูลจะรอในเครื่องและส่งให้เองเมื่อเชื่อมต่อได้ (มีแถบสีเหลืองบอกด้านบน)

## บทบาทและสิทธิ์
- **หัวหน้า / ผู้ดูแลระบบ** — ทำได้ทุกอย่าง รวมถึงลบผู้สูงอายุ จัดการผู้ใช้ ตั้งค่าศูนย์ สำรองข้อมูล
- **พยาบาล** — เพิ่ม/แก้ข้อมูลผู้สูงอายุ ยา คำสั่งแพทย์ เกณฑ์ค่าผิดปกติ และแก้บันทึกของทุกคน
- **ผู้ช่วยดูแล** — บันทึกสัญญาณชีพ บันทึกพยาบาล การให้ยา แก้/ลบได้เฉพาะที่ตัวเองบันทึก

ทุกการเพิ่ม แก้ไข ลบ ถูกเก็บในเมนู "ประวัติการแก้ไข" (ใคร เมื่อไร เปลี่ยนจากอะไรเป็นอะไร) ลบประวัติไม่ได้
การลบข้อมูลเป็นการซ่อน ข้อมูลเดิมยังดูได้ในประวัติ

## โครงสร้างไฟล์
```
server.py         เซิร์ฟเวอร์ + ฐานข้อมูล (Python ล้วน) — สิทธิ์ผู้ใช้อยู่ที่ can_write()
login.html        เข้าสู่ระบบ / ตั้งค่าครั้งแรก
index.html        หน้าหลัก / รายชื่อผู้สูงอายุ
profile.html      ประวัติรายบุคคล + เกณฑ์ค่าผิดปกติเฉพาะคน
medication.html   ตารางให้ยา (เลือกวันย้อนหลังได้ รองรับยาให้เมื่อมีอาการ)
record.html       บันทึกการตรวจ + บันทึกทางการพยาบาล (เลือกวันย้อนหลังได้)
report.html       รายงานและใบส่งตัวไปโรงพยาบาล
history.html      ประวัติการแก้ไข
users.html        จัดการผู้ใช้ (หัวหน้าเท่านั้น)
css/style.css     สีและสไตล์ทั้งหมด
js/data.js        ข้อมูลตัวอย่างและค่าคงที่ (รอบยา สถานะ ข้อความสำเร็จรูป)
js/core.js        การเชื่อมต่อเซิร์ฟเวอร์ สิทธิ์ เกณฑ์ค่าผิดปกติ ฟอร์ม
js/reports.js     รายงานทุกแบบ
js/pages.js       โค้ดของแต่ละหน้า
data/             ฐานข้อมูลและไฟล์สำรอง (สร้างเองตอนรันครั้งแรก — ห้ามลบ)
```

## สิ่งที่ใช้งานได้แล้ว
- เพิ่ม / แก้ไข / ลบ ผู้สูงอายุ (ปุ่ม "+ เพิ่มผู้สูงอายุ" หน้าหลัก, "แก้ไขข้อมูล" หน้าประวัติ) รวมญาติ ข้อควรระวัง นัดหมาย
- เพิ่ม / แก้ไข / ลบ ยา (หน้าประวัติ หรือหน้าตารางให้ยา) ทั้งยาประจำตามรอบ และยาให้เมื่อมีอาการ (PRN)
- ตารางให้ยา: วันนี้กด 1 ครั้ง = ให้แล้ว, 2 ครั้ง = ไม่ได้ให้ (ต้องใส่เหตุผล), 3 ครั้ง = ล้าง
  เลือกวันที่ผ่านมาได้ เพื่อบันทึกย้อนหลังพร้อมเวลาที่ให้จริง ยา PRN กด "+ บันทึกการให้" พร้อมใส่อาการ
- บันทึกสัญญาณชีพ — ค่าผิดปกติขึ้นสีแดงอัตโนมัติ เลือกดู/บันทึกวันย้อนหลังได้
  เกณฑ์มาตรฐานอยู่ที่ `DEFAULT_LIMITS` ใน core.js และตั้งเกณฑ์เฉพาะคนได้ที่หน้าประวัติ (ปุ่ม "ตั้งเกณฑ์เฉพาะคนนี้")
- บันทึกพยาบาล: ปุ่มงานที่ทำบ่อยเติมข้อความให้, แก้ไข/ลบได้, คำนวณเวลาพลิกตัวครั้งถัดไป, สรุปขับถ่ายวันนี้
- คำสั่งแพทย์: เพิ่ม / แก้ไข / ยกเลิก ในหน้าบันทึกอาการ
- **ใบส่งตัวไปโรงพยาบาล** (ปุ่ม "พิมพ์ใบส่งตัวไป รพ." ในหน้าประวัติและหน้าบันทึกอาการ)
  ดึงข้อมูลผู้ป่วย แพ้ยา สัญญาณชีพล่าสุด ยาและเวลาที่ให้ครั้งล่าสุด บันทึก 24 ชม. มาให้เอง
  กรอกเหตุผลที่ส่ง อุปกรณ์ที่ติดตัว ผู้นำส่ง แล้วพิมพ์ — ช่องที่เว้นว่างจะพิมพ์เป็นเส้นไข่ปลาให้เขียนด้วยมือ
- รายงานอีก 4 แบบ สร้างจากข้อมูลจริงตามช่วงวันที่: สรุปสุขภาพ, การให้ยา, ส่งเวร, เหตุการณ์ผิดปกติ
  ทุกรายงานเป็นรูปแบบเอกสารทางการ ขนาด A4 มีหัวศูนย์ หัวข้อเรียงเลข ตารางมีเส้น และช่องลงชื่อ
  พิมพ์ / PDF / ดาวน์โหลดเป็นไฟล์ .csv เปิดด้วย Excel ได้
- เข้าสู่ระบบด้วยบัญชีของแต่ละคน ชื่อจะติดไปกับทุกบันทึก หัวหน้าตั้งชื่อศูนย์ได้ใต้เมนูซ้าย

## ข้อควรรู้เรื่องความปลอดภัย (PDPA)
ข้อมูลสุขภาพเป็นข้อมูลอ่อนไหว ระบบนี้ออกแบบให้ใช้**ภายใน Wi-Fi ของศูนย์เท่านั้น**
- รหัสผ่านถูกเข้ารหัสก่อนเก็บ ใส่ผิด 5 ครั้งจะถูกพัก 10 นาที เข้าสู่ระบบค้างได้ 12 ชั่วโมง
- อย่าเปิดพอร์ตให้เข้าจากอินเทอร์เน็ต ถ้าต้องใช้นอกศูนย์ ต้องตั้ง HTTPS (เช่น ผ่าน Cloudflare Tunnel หรือ Tailscale) ก่อน
- ตั้งรหัสผ่านเครื่องที่รันเซิร์ฟเวอร์ และอย่าใช้บัญชีร่วมกัน
- แท็บเล็ตที่ใช้ร่วมกัน ให้กด "ออกจากระบบ" ทุกครั้งเมื่อเปลี่ยนเวร
